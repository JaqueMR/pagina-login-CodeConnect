# Curso de React - Construindo Componentes com JSX

## Curso **React: Construindo Componentes com JSX**

### O que eu aprendi no curso

- **Estruturação de uma página de login:** Aprendi a construir uma página de login utilizando componentes React, o que ajudou a entender como organizar a interface de maneira modular.
- **Manipulação de eventos:** Consegui manipular eventos para interações do usuário com a interface, o que deixou o app mais dinâmico e responsivo.
- **Integração com bibliotecas e ferramentas:** Fiz a integração das bibliotecas **React**, **React DOM** e da ferramenta **Babel** no meu projeto via CDN, facilitando o uso de JSX e renderização de componentes.
- **Gerenciamento de estados:** Usei o **useState** para gerenciar o estado da aplicação e garantir que a interface fosse atualizada conforme as interações do usuário.
- **Componentes dinâmicos com props:** Transformei meus componentes em dinâmicos usando **props** e **props children**, permitindo maior flexibilidade na renderização e reutilização de código.

### O que fiz no curso

1. **Conhecendo o React:** Comecei com a introdução ao React, configurando o ambiente e o projeto, e criando a estrutura inicial.
2. **Componentização de interfaces:** Entendi como dividir a interface em componentes reutilizáveis usando **JSX**, facilitando a manutenção e a organização do código.
3. **Renderizando componentes:** Aprendi a renderizar componentes e criar elementos novos dentro da aplicação, manipulando a estrutura da página dinamicamente.
4. **Dinamizando componentes:** Coloquei em prática a utilização de **props** e **props children** para criar componentes flexíveis que podem receber diferentes tipos de conteúdo.
5. **Gerenciando estados:** Usei o **useState** para atualizar dinamicamente o conteúdo com base nas interações do usuário, como a digitação no campo de login.
6. **Manipulação de eventos:** Trabalhei com eventos, como a alteração de inputs e a checagem de opções no formulário de login.

### Observação

Este projeto não implementa autenticação real na página de login, sendo apenas uma visualização da interface. O foco do curso foi no aprendizado da estruturação de componentes e no gerenciamento de estados com React. Se eu for integrar autenticação posteriormente, precisarei configurar uma API para validar as credenciais e gerenciar sessões de usuário.
